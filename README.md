# Government Graduate College Okara — Website

A front-end website project inspired by the official **Government Graduate College Okara** website. This project was created to practice and demonstrate modern HTML and CSS layout techniques, responsive interface design, navigation, cards, event sections, and footer components.

## 🌐 Project Overview

The website presents a college-style homepage featuring:

* Navigation bar with multiple sections
* College branding and search interface
* Hero section highlighting educational excellence
* Historical background and academic information
* Financial aid and student support section
* Academic programs and student services
* Student, alumni, and degree statistics
* College events and achievements
* Principal's message
* Contact information and social media section
* Responsive-style page structure using HTML and CSS

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **Font Awesome**
* **Google Fonts / Web Fonts**
* Flexbox and CSS layout techniques

Font Awesome is used for interface and social-media icons.

## ✨ Main Sections

### Header & Navigation

Includes the college logo area, department links, website directory, search field, and primary navigation such as Home, About, Admissions, Academies, Research, Student Affairs, and Financial Aid.

### Hero Section

Highlights the institution's educational history with the heading **"75+ Years of Educational Excellence"** and an introduction focused on knowledge, leadership, and innovation.

### Academic Information

Contains sections covering the college's historical background, academic success, financial assistance, scholarships, and student support.

### Events

Displays multiple college events and achievements, including student competitions, alumni achievements, emergency-awareness sessions, and student activities.

### Principal's Message

Includes a dedicated section containing the principal's message and information about the college's educational mission and student opportunities.

### Footer

The footer contains information about students, alumni, staff, academic programs, research, jobs, social media, address, phone number, and email.
